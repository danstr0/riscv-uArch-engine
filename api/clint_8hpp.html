Detailed Description

Core-Local Interruptor (CLINT)

Provides one shared 64-bit mtime counter plus, for each hart, a 64-bit mtimecmp comparator (drives mip.MTIP) and and msip register (drives mip.MSIP, used for inter-processor interrupts).

MMIO register map (SiFive CLINT layout)
┌──────────────────┬──────────────┬───────┬────────────────────────────────┐
│ Offset │ Name │ Width │ Description │
├──────────────────┼──────────────┼───────┼────────────────────────────────┤
│ 0x0000 + 4·hart │ msip[hart] │ u32 │ Bit 0 drives mip.MSIP │
│ 0x4000 + 8·hart │ mtimecmp[h] │ u64 │ Timer compare (lo @ +0, hi +4) │
│ 0xBFF8 │ mtime │ u64 │ Shared timer (lo @ +0, hi +4) │
└──────────────────┴──────────────┴───────┴────────────────────────────────┘
Timebase
mtime advances once every cycles_per_tick core cycles (default 1). Real platforms run mtime from a fixed-frequency timebase that is independent of the core clock; a divider > 1 models that.
Writing mtime
Software may write mtime (as the spec allows). The CLINT then keeps an offset from the simulation clock so mtime continues counting from the written value.
See also
RISC-V Privileged ISA specification, Section 3.2.1 (Machine Timer Registers); SiFive CLINT documentation for the register layout.
