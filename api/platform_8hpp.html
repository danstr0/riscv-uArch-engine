Detailed Description

The physical platform shared by all core models: RAM, devices, the physical memory map, and interrupt wiring.

A Platform owns everything outside the cores: demand-allocated RAM, a CLINT (timer + software interrupts), a PLIC (external interrupts), and an optional NIC. It builds one MMIO bus per hart and routes each hart's MTIP / MSIP / MEIP lines to that hart's CSR file. Any core model that exposes a CSRFile can be attached, so the single-cycle CPU, the PipelinedCPU, and MultiCoreCPU all see the same platform.

The device addresses follow the common SiFive / QEMU virt convention and do not depend on RAM size. Accesses that hit no region fault.
Bus topology
Device regions are uncached: a hart's bus routes them straight to the device. Only the RAM range is forwarded to the hart's "downstream" memory (its L1 cache, or RAM itself when caches are disabled).
PLIC contexts
The cores only implement M-mode, so PLIC context h is hart h's M-mode context.
