Detailed Description

A complete single-hart system.

SingleCoreSystem<Core> assembles a Platform (RAM + CLINT + PLIC), an optional cache hierarchy in front of RAM, and one core of type Core (CPU or PipelinedCPU). The core's loads and stores go through the platform's bus, so programs reach devices at their memory-mapped addresses, and the platform's interrupt lines drive the core's mip register.

Split or unified L1
With l1i disabled (the default), l1d is a unified L1 serving both fetches and data. With l1i enabled, fetches go to a separate read-only I-cache. An I-cache refill sees the newest data, including dirty D-cache lines, but a line already in the I-cache can go stale after a store until the hart runs fence.i, as RISC-V permits.
Time
Each step() advances the core (one instruction for CPU, one clock for PipelinedCPU) and then advances the devices to the core's cycle count, so mtime tracks simulated time for both models.
SingleCoreSystem<PipelinedCPU> sys({ .platform = { .ram_size = 1 << 20 } });
sys.load_program(0, code);
sys.run_until([&] { return sys.core().halted(); });
